> 断网可用，数据只存在你自己电脑上，不注册、不联网、不上传。

## 功能特性

### 📝 待办管理
- 添加、修改、删除待办事项
- 点一下勾选框就能标记完成 / 取消完成
- **按状态筛选**：全部 / 未完成 / 已完成（标签上带实时数量）
- **关键字搜索**：输入即搜，标题和描述都能搜到
- 支持优先级（低 / 中 / 高）、分类标签、详细描述

### ♻️ 回收站
- 删除的待办会移入回收站，**不会立即销毁**
- 支持**还原**：将误删的待办恢复到列表中
- 支持**彻底删除**与**清空回收站**，两处均有二次确认
- 回收站中的待办不会出现在列表、搜索、统计与日历中，也不会触发提醒

### 🔔 系统级提醒
- 到达提醒时间时，在屏幕右下角弹出 Windows 系统通知
- 通知需**手动关闭**，不会像普通通知那样自动消失
- **关闭浏览器后仍可收到提醒**
- 支持「稍后提醒」（默认推迟 10 分钟）
- 同一条提醒不会重复弹出，也不会遗漏

### 📅 日历视图
- 月历网格视图，可直观查看各日期是否有待办
- **点击未来某一天，即可在该日期创建待办**
- 没有截止时间的任务单独列在「未安排日期」面板中

### 🪟 桌面悬浮窗
一个一直待在桌面上的小窗口，**关掉浏览器它也在**。

- **待在桌面上，不打扰你**：它贴在桌面这一层，打开浏览器或别的软件时会被盖住，
  按 **Win + D** 回到桌面就能看到它。（想让它压在最上面，右键标题栏勾「总在最前面」）
- **能自由摆放**：鼠标移到**窗口任意边缘或角落**就能拖动移动、拖动改大小，
  位置和大小会自动记住。改完大小，里面的文字会自动重新排版。
- **外观随便调**：右上角 **⚙** 里可以调**字号、字体（宋体 / 楷体 / 仿宋 / 黑体…）、
  字体颜色、背景颜色、透明度**；也可以用一键配色（黑玻璃 / 纸白 / 墨黑 / 护眼绿 / 暖茶 / 高对比）。
- **按日期分块显示**，每一块都**带着具体日期**：
  `已过期 9-11` / `今天 9-14` / `明天 9-15` / `七天内 9-16 ~ 9-21` / `之后 10-24` / `未安排日期`。
  点顶部的 **[日期 ▾]** 可以换成**按优先级**或**按分类**分块。
- **在窗口里就能干活**：点一行的任意位置弹出完整编辑框（标题 / 分类 / 重要度 /
  截止时间 / 提醒时间 / 详细描述），点方框切换完成，底部输入框**回车**即可新建，
  右键还有「稍后提醒」「删除」。
- **时间有日历**：截止和提醒时间旁边有个 📅 按钮，点一下弹出日历挑日期，
  不用自己算「下周三到底是几号」。
- **提醒照样收得到**：窗口在不在前面都能收到系统通知，窗口里也会浮出提示。

> **开启方式**：网页设置页 → 「桌面悬浮窗」→ 打开总开关。
> **默认是关闭的** —— 它是个会开机自启的功能，默认打开会让您开机时莫名多出一个窗口。
>
> **想让它开机就出现**：先在网页设置页打开「开机自动启动」，
> 再回到悬浮窗那一块打开「开机自启时也显示悬浮窗」。

### ⚙️ 设置
- **一键开启开机自启**（不需要管理员权限，随时可撤销）
- **桌面悬浮窗的开关与全部外观设置**（见上一节）
- 数据库**自动备份**（每次启动备份一次，保留最近 7 份）
- 一键测试系统通知
- 一键退出程序、打开数据目录

## 关于「透明」和「字体清晰」——两个容易混的概念

先分清两个方向相反的词，**设置里写的是前者**：

| 说法 | 含义 | 换算 |
| --- | --- | --- |
| **不透明度** | 数字越大越不透明、越看不透 | 设置里滑块显示的就是它 |
| **透明度** | 数字越大越透 | **透明度 = 100% − 不透明度** |

**出厂默认：黑色背景 + 不透明度 70%**，也就是**黑色背景 + 透明度 30%**。
可调范围 70% 透明度 ~ 完全不透明（不透明度 30% ~ 100%）。

### 调得更透，损失的是「对比度」而不是「清晰度」

这两件事经常被混为一谈，但它们是**不同的量**：

| | 是什么 | 受什么影响 |
| --- | --- | --- |
| **清晰度（锐利）** | 笔画边缘利不利、有没有糊成一团 | 由**渲染方式**决定 —— 程序已声明 DPI 感知，不让 Windows 拉伸窗口，所以字始终是锐利的 |
| **对比度（好不好读）** | 字和背景的亮度差有多大 | **会**随透明度下降而变小 —— 桌面透进来越多，字越"发白"，读起来越吃力 |

所以：**把窗口调得很透，字不会变糊，但会变得难读。**
这不是"软件没做好"，而是"半透明"这件事本身的物理后果
（本质是和桌面底色混合，颜色按比例变淡，边缘依然锐利）。

想最好读就把不透明度调到 100%。默认的 70% 在多数桌面上是"既透又读得清"的折中。

> 想改默认值或范围：改 `app/config.py` 里的
> `FLOATING_DEFAULT_OPACITY`（默认）和 `FLOATING_MIN_OPACITY`（下限）。

## 启动方式

### 方式一：安装包（推荐，无需安装 Python）

1. 从本仓库的 [Releases](../../releases) 页面下载 `OfflineTodoList-Setup.exe`
2. 运行安装包，点击「开始安装」
3. 从**开始菜单**或**桌面快捷方式**启动

安装包约 **32 MB**，**不需要管理员权限**。

> **卸载**：Windows「设置 → 应用 → 已安装的应用 → 离线待办清单」。
> 卸载不会删除用户数据，重新安装后仍然存在。

### 更新到新版本

安装新版本**无需先卸载旧版本**：直接运行新版的安装包，点击「开始安装」即可。

1. 从 [Releases](../../releases) 下载新版的 `OfflineTodoList-Setup.exe`
2. 运行安装包，点击「开始安装」
3. 安装完成后从开始菜单启动（快捷方式会自动更新）

覆盖安装时，安装程序会自动完成以下操作：

| 操作 | 说明 |
| --- | --- |
| 关闭正在运行的旧版本 | 避免程序文件被占用 |
| 替换程序文件 | 整个程序目录被替换为新版本 |
| 更新开始菜单与桌面快捷方式 | 不会产生重复图标 |
| 更新「应用和功能」中的版本记录 | 不会出现两条卸载项 |

#### 升级与数据的关系

程序文件与用户数据分别存放，升级只替换程序文件：

```
程序文件（会被替换）  %LOCALAPPDATA%\Programs\OfflineTodoList
用户数据（保持不变）  %LOCALAPPDATA%\OfflineTodoList\data\todo.db
```

升级过程不会改动用户数据（待办、备份、日志）。此外，程序每次启动也会自动备份一次（保留最近 7 份）。

#### 提示「无法替换旧版本」时

该提示表示程序仍在运行。安装程序采用「先准备新版、再整体替换」的方式，替换失败会整体中止，**旧版本保持完好**，不会留下安装到一半的程序。

按以下步骤处理后，重新运行安装包：

1. 打开程序，在设置页点击「退出程序」
2. 或在任务管理器中结束 `OfflineTodoList.exe`
3. 重新运行安装包

### 方式二：源码运行

需要先装 **Python 3.10 或更高版本**。

```bash
pip install -r requirements.txt    # 安装依赖（只有 4 个）
python run.py                      # 启动，浏览器会自动打开
```

浏览器会打开 `http://127.0.0.1:8000`。

### 方式三：批处理入口

项目根目录提供以下可直接双击运行的脚本，无需使用命令行：

| 文件 | 用途 |
| --- | --- |
| **`start.bat`** | 启动程序 |
| **`test_reminder.bat`** | 测试提醒（造一条 20 秒后触发的提醒）|
| **`check.bat`** | 自检（检查程序是否正常）|
| **`clean.bat`** | 清理缓存文件（不会碰数据）|

## 使用说明

### 添加待办

在页面顶部填写：

| 字段 | 说明 |
| --- | --- |
| **标题** | 必填 |
| 截止时间 | 会弹出日历和时间选择器 |
| 提醒时间 | 到达该时间时弹出系统通知。填写后**提醒开关会自动开启**，无需另行勾选 |
| 优先级 | 低 / 中 / 高，列表中用**左侧色条**区分 |
| 分类 | 自由填写，例如"学习""生活""工作" |
| 描述 | 可选，支持换行 |

点击「**添加**」后，待办立即出现在列表中；表单自动清空并将光标移回标题输入框，便于连续录入。

### 标记完成

点条目左边的**复选框**。再点一次可以取消完成。

已完成的待办会**变灰并加删除线**。

### 修改待办

将鼠标移到条目上并点击「**编辑**」，在弹出的居中窗口中修改后点击「保存修改」。

> 若在未保存的情况下关闭编辑窗口，程序会先要求确认，避免修改内容丢失。

### 删除待办

点击「**删除**」后会弹出确认框，确认后待办被移入回收站。

> 回收站中的待办可以**还原**，也可以**彻底删除**。
> 此外程序每次启动会自动备份，可用于恢复更早的数据状态。

### 筛选和搜索

- **筛选**：点列表上方的「全部 / 未完成 / 已完成」标签，数字是实时数量
- **搜索**：右上角搜索框，输入即搜（标题和描述都能搜到）

### 设置提醒

添加或编辑待办时填写**提醒时间**即可。到达提醒时间时会产生三种提示：

1. 屏幕右下角弹出 Windows 系统通知（需手动关闭，不会自动消失）
2. 浏览器页面右下角出现提醒卡片（含操作按钮）
3. 播放一次提示音

#### 提醒与浏览器的关系

提醒由程序自身的后台线程触发，**与浏览器是否运行无关**。该线程每 20 秒扫描一次到点任务，直接调用 Windows 系统通知，全程不经过浏览器。

| 状态 | 是否提醒 |
| --- | --- |
| 关闭浏览器标签页 | 是 |
| 关闭整个浏览器 | 是 |
| 电脑锁屏，或正在使用其它软件 | 是 |
| 程序本身已退出（控制台关闭，或设置页点击「退出程序」） | 否 |

若需要程序长期在后台待命，可在**设置页**开启「**开机自启**」：
开启后程序会在登录 Windows 时静默运行（不显示窗口，也不打开浏览器），到达提醒时间自动通知。
建议同时关闭「开机时自动打开浏览器」。

提醒卡片提供以下操作：

| 按钮 | 作用 |
| --- | --- |
| **标记完成** | 将该待办标记为已完成 |
| **稍后提醒** | 推迟 10 分钟后再次提醒 |
| **×** | 关闭该提醒（待办本身不变） |

建议首次使用时在**设置页**点击「**发一条测试通知**」进行验证。
若未收到通知，通常是因为 Windows 的**专注助手**或**勿扰模式**处于开启状态，
可在任务栏右下角的通知中心查看。

### 日历

点顶部导航的「**日历**」：

| 区域 | 说明 |
| --- | --- |
| 顶部 | `‹ 上月` / 月份 / `下月 ›` / `今天` |
| 日期格子 | 显示那天有几条待办，最多显示 3 条 |
| 颜色 | **今天**蓝色边框；**非本月**灰底；**过去**淡色 |
| 选中某天 | 下面显示那天的待办 + 一个快速添加框 |
| 未安排日期 | 没有截止时间的待办（它们不会出现在月历上）|

**在指定日期添加待办**：点击该日期，在下方输入标题后点击「添加」。

> **过去的日期不支持新建待办**（输入框会置灰）。

### 设置页

点顶部导航的「**设置**」，有六个板块：

| 板块 | 能做什么 |
| --- | --- |
| **开机自启** | 开关开机自动启动；选择是否同时打开浏览器 |
| **桌面悬浮窗** | 开关悬浮窗；调字号 / 字体 / 颜色 / 透明度；切换分块方式；立即显示 / 重启 / 隐藏窗口 |
| **数据** | 查看待办数量、数据库大小；一键打开数据目录 |
| **备份** | 查看备份份数；一键「立即备份」；打开备份目录 |
| **系统通知** | 查看通知是否可用；**发测试通知**；切换通知身份模式；开关页面提示音 |
| **关于** | 版本信息、打开接口文档、**退出程序** |

#### 开机自启

开启后，每次登录 Windows 都会自动在后台启动服务。

#### 桌面悬浮窗

这里可以开关悬浮窗，并调整它的外观。几个要点：

| 我想…… | 去哪儿调 |
| --- | --- |
| 开关悬浮窗 | 本板块最上面的「开启悬浮窗」 |
| 让它开机就出现 | 先开「开机自动启动」，再开这里的「开机自启时也显示悬浮窗」 |
| 把藏起来的窗口叫回来 | 点「立即显示」 |
| 窗口卡住了 | 点「重启窗口」 |
| 换字号 / 字体 / 颜色 / 透明度 | 本板块的「外观」一节 |
| 换分块方式（日期 / 优先级 / 分类） | 本板块的「显示内容」一节，或直接点悬浮窗上的 **[日期 ▾]** |
| 恢复成默认外观 | 点最下面的「恢复默认设置」（**只会重置外观和位置，不会动您的待办**） |

> **窗口没出现怎么办？**
> ① 先点「立即显示」；② 看本板块「窗口进程」那一行的说明；
> ③ 还不行就点「打开窗口日志目录」，把 `window.log` 里的报错发我；
> ④ 如果显示「已停止自动重试」，那说明它连续启动失败多次后主动停了 ——
> 点「重启窗口」即可重新尝试。

#### 在悬浮窗上能做什么

| 我想…… | 怎么做 |
| --- | --- |
| 移动窗口 | **鼠标移到窗口任意边缘**（光标变四向箭头）拖动 |
| 改大小 | **鼠标移到边缘或角落**（光标变 ↔ ↕ ⤡）拖动 |
| 编辑一条待办 | **点那一行的任意位置** |
| 标记完成 | 点最左边的 ☐（或双击整行） |
| 新建待办 | 底部输入框**回车**；或点工具栏的 **＋**（能填更多字段） |
| 挑日期 | 编辑框里时间旁边的 **📅** |
| 稍后提醒 / 删除 | 在那一行**点右键** |
| 改字号 / 颜色 / 透明度 / 字体 | 点右上角 **⚙** |
| 换分块方式 | 点顶部的 **[日期 ▾]** |
| 收起窗口（**不算关闭功能**） | 点 **✕** —— 下次开机它还会出现 |
| **真正关掉这个功能** | **⚙** 里的「关闭悬浮窗」 |

### 数据与备份

#### 数据存放位置

| 运行方式 | 数据位置 |
| --- | --- |
| 安装包版 | `%LOCALAPPDATA%\OfflineTodoList\data\` |
| 源码运行 | 项目目录下的 `data\` |

复制整个 `data` 文件夹即可完成完整备份。
程序每次启动也会自动备份到 `data\backups\`（保留最近 7 份），
在设置页点击「打开数据目录」可直接打开该目录。

#### 删除与恢复

删除的待办会移入**回收站**，可在回收站页面选择**还原**或**彻底删除**。
此外，程序每次启动都会自动备份，可用于恢复更早的数据状态。

#### 系统支持

目前主要面向 **Windows**：系统通知与开机自启依赖 Windows 的系统能力。

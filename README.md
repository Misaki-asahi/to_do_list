# 离线待办清单 · Offline Todo List

> 一个**完全离线**的本地待办与提醒工具。
> 断网可用，数据只存在你自己电脑上，不注册、不联网、不上传。

## 功能特性

### 📝 待办管理
- 添加、修改、删除待办事项
- 点一下勾选框就能标记完成 / 取消完成
- **按状态筛选**：全部 / 未完成 / 已完成（标签上带实时数量）
- **关键字搜索**：输入即搜，标题和描述都能搜到
- 支持优先级（低 / 中 / 高）、分类标签、详细描述

### 🔔 系统级提醒
- 到点在**屏幕右下角**弹出 Windows 系统通知
- **不点掉就不会消失** —— 不会像普通通知那样几秒就没
- **浏览器关掉也能收到提醒**
- 支持"稍后提醒"（默认推迟 10 分钟）
- 同一条提醒**绝不重复弹、也绝不漏弹**

### 📅 日历视图
- 月历网格，一眼看清哪几天有事
- **点未来的某一天，直接在那天创建待办**
- 没有截止时间的任务单独放在"未安排日期"面板

### ⚙️ 设置
- **一键开启开机自启**（不需要管理员权限，随时可撤销）
- 数据库**自动备份**（每次启动备份一次，保留最近 7 份）
- 一键测试系统通知
- 一键退出程序、打开数据目录

## 启动方式

### 方式一：安装包（推荐，不用装 Python）

1. 从本仓库的 [Releases](../../releases) 页面下载 `OfflineTodoList-Setup.exe`
2. **双击运行** → 点「开始安装」
3. 从**开始菜单**或**桌面快捷方式**启动

安装包约 **32 MB**，**不需要管理员权限**。

> 📌 **卸载**：Windows「设置 → 应用 → 已安装的应用 → 离线待办清单」。
> **卸载不会删除你的待办数据**，重新安装后还在。

### 更新到新版本（不用先卸载）

**装了新版本？直接装就行 —— 不需要卸载旧版本。**

1. 从 [Releases](../../releases) 下载新版的 `OfflineTodoList-Setup.exe`
2. **双击运行，直接点「开始安装」**
3. 装完从开始菜单启动即可（快捷方式会自动更新）

安装程序会自己处理这些事：

| 它做了什么 | 说明 |
| --- | --- |
| 自动关闭正在运行的旧版本 | 否则文件被占用，装不进去 |
| 替换程序文件 | 旧程序目录整个换掉 |
| 更新开始菜单 / 桌面快捷方式 | 不会多出重复的图标 |
| 更新「应用和功能」里的版本记录 | 不会出现两条卸载项 |

#### 你的待办数据不会被删

**程序和你的数据是分开存放的：**

```
程序（会被替换）  %LOCALAPPDATA%\Programs\OfflineTodoList
你的数据（不动）  %LOCALAPPDATA%\OfflineTodoList\data\todo.db
```

升级只动上面那个，**下面那个（你的待办、备份、日志）完全不碰**。
而且程序每次启动还会自动备份一次（保留最近 7 份），多一层保险。

#### 如果安装报错说「无法替换旧版本」

**说明程序还在运行。** 按提示处理：

1. 打开程序 → 设置页 → 点「退出程序」
2. 或者：任务管理器 → 找到 `OfflineTodoList.exe` → 结束任务
3. 再重新运行安装包

> **不用担心**：这种情况下**旧版本是完好无损的**。
> 安装程序用的是「先准备好新版、再整目录替换」的方式 ——
> 替换失败就整体中止，**不会留下一个装了一半的程序**。

### 方式二：源码运行

需要先装 **Python 3.10 或更高版本**。

```bash
pip install -r requirements.txt    # 安装依赖（只有 4 个）
python run.py                      # 启动，浏览器会自动打开
```

浏览器会打开 `http://127.0.0.1:8000`。

### 方式三：双击工具（不想敲命令）

项目根目录里有几个**双击即用**的工具：

| 文件 | 用途 |
| --- | --- |
| **`start.bat`** | 启动程序 |
| **`test_reminder.bat`** | 测试提醒（造一条 20 秒后触发的提醒）|
| **`check.bat`** | 自检（检查程序是否正常）|
| **`clean.bat`** | 清理缓存文件（不会碰数据）|

## 使用说明

### 添加待办

在页面顶部填写：

| 字段 | 说明 |
| --- | --- |
| **标题** | 必填 |
| 截止时间 | 点一下会弹出日历和时间选择器 |
| 提醒时间 | 到点会弹系统通知。**填了它，提醒开关会自动打开**，不用另外勾选 |
| 优先级 | 低 / 中 / 高，列表中用**左侧色条**区分 |
| 分类 | 自由填写，例如"学习""生活""工作" |
| 描述 | 可选，支持换行 |

填好点「**添加**」，列表里立刻就会出现，表单会自动清空、光标回到标题框（方便连续录入）。

### 标记完成

点条目左边的**复选框**。再点一次可以取消完成。

已完成的待办会**变灰并加删除线**。

### 修改待办

鼠标移到条目上 → 点「**编辑**」→ 弹出**居中的编辑窗口** → 改完点「保存修改」。

> 💡 编辑时如果改了内容没保存就想关掉，程序会先问你"确定放弃修改吗"，不会让你白改。

### 删除待办

点「**删除**」→ 会弹出确认框 → 点「确定」才会真的删掉。

> ⚠️ **删除后无法恢复。**（程序每次启动会自动备份，需要时可以找回来。）

### 筛选和搜索

- **筛选**：点列表上方的「全部 / 未完成 / 已完成」标签，数字是实时数量
- **搜索**：右上角搜索框，输入即搜（标题和描述都能搜到）

### 设置提醒

添加或编辑待办时，填上**提醒时间**即可。到点会发生三件事：

1. **屏幕右下角弹出 Windows 系统通知**（不点掉不会消失）
2. 浏览器里的页面**右下角出现一张提醒卡片**（带操作按钮）
3. 听到一声"叮咚"提示音

#### ⭐ 关掉浏览器也会提醒

**这一点很关键，也是最多人问的：**

| 你关掉了什么 | 还会提醒吗 |
| --- | --- |
| 浏览器标签页 | ✅ **会** |
| 整个浏览器 | ✅ **会** |
| 电脑锁屏 / 你在用别的软件 | ✅ **会** |
| 程序本身（那个黑窗口，或设置页点「退出程序」） | ❌ 不会 |

**为什么？** 因为提醒不是网页发的 —— 它由**程序自己的后台线程**负责：
每 20 秒检查一次有没有到点的任务，到点就直接调用 Windows 系统通知。
**浏览器从头到尾都不参与**，所以关不关它没有任何影响。

> 📌 **想让它"一直在后台待命"？**
> 打开**设置页** → 把「**开机自启**」打开即可。
> 这样开机后程序会静默运行（不弹窗口、不开浏览器），到点自动提醒，
> 你平时完全不用管它。
>
> 建议同时把「开机时自动打开浏览器」**关掉** —— 保持安静。

提醒卡片上可以：

| 按钮 | 作用 |
| --- | --- |
| **标记完成** | 把这条待办标记为已完成 |
| **稍后提醒** | 推迟 10 分钟再提醒一次 |
| **×** | 关掉这个提醒（任务本身不变）|

> 📌 **第一次使用建议先测试一下**：打开**设置页** → 点「**发一条测试通知**」。
> 如果没看到通知，最常见的原因是 Windows 的**专注助手 / 勿扰模式**开着
> （点任务栏右下角的通知中心看一眼）。

### 日历

点顶部导航的「**日历**」：

| 区域 | 说明 |
| --- | --- |
| 顶部 | `‹ 上月` / 月份 / `下月 ›` / `今天` |
| 日期格子 | 显示那天有几条待办，最多显示 3 条 |
| 颜色 | **今天**蓝色边框；**非本月**灰底；**过去**淡色 |
| 选中某天 | 下面显示那天的待办 + 一个快速添加框 |
| 未安排日期 | 没有截止时间的待办（它们不会出现在月历上）|

**在某天添加待办**：点那一天 → 在下面输入标题 → 点「添加」。

> ⚠️ **过去的日期不能新建待办**（输入框会变灰）。

### 设置页

点顶部导航的「**设置**」，有五个板块：

| 板块 | 能做什么 |
| --- | --- |
| **开机自启** | 开关开机自动启动；选择是否同时打开浏览器 |
| **数据** | 查看待办数量、数据库大小；一键打开数据目录 |
| **备份** | 查看备份份数；一键「立即备份」；打开备份目录 |
| **系统通知** | 查看通知是否可用；**发测试通知**；切换通知身份模式；开关页面提示音 |
| **关于** | 版本信息、打开接口文档、**退出程序** |

#### 开机自启说明

打开开关后，每次登录 Windows 都会**自动在后台启动服务**。

<details>
<summary><b>数据存在哪？怎么备份？</b></summary>

| 运行方式 | 数据位置 |
| --- | --- |
| 安装包版 | `%LOCALAPPDATA%\OfflineTodoList\data\` |
| 源码运行 | 项目目录下的 `data\` |

**把整个 `data` 文件夹复制走，就是完整备份。**

程序每次启动也会自动备份到 `data\backups\`（保留最近 7 份）。
在设置页点「打开数据目录」可以直接打开它。

</details>

<details>
<summary><b>删掉的东西能恢复吗？</b></summary>

**不能。** 目前是直接删除。

但程序每次启动会自动备份，可以去 `data\backups\` 里找回最近的状态。

</details>

<details>
<summary><b>能在别的系统上用吗？</b></summary>

目前主要面向 **Windows**：系统通知和开机自启依赖 Windows 的能力。

</details>

## 二、项目一句话

**离线待办清单**：本地优先（Local-First）的待办与提醒工具，断网可用，
数据只存在自己电脑上的一个 SQLite 文件里。

- **技术栈**：Python + FastAPI + 原生 HTML/CSS/JS（**前端零构建**）
  + 桌面悬浮窗（Python 标准库 tkinter，**零新依赖**）
- **仓库根目录**：`win11/`（`.git` 在这里）
- **规模**：约 16,000 行代码；14 个测试文件
- **版本号在两处，必须一致**：`app/config.py` 与 `installer/install.py` 的 `APP_VERSION`
- **出厂默认（v0.4.2 起）**：黑底白字 / 宋体 **10 磅** / 不透明度 **0.90**（透 10%）/
  **悬浮窗默认开启** / **开机自启默认开启且静默（不弹浏览器）** / 不置顶

### 3.2 桌面悬浮窗（需求 10）—— **用户原话照录**

> 增加桌面悬浮窗，能自由移动，控制大小，调整背景透明度 字号和颜色，
> 设置提醒，编辑内容，可以设置按日期或优先级或分类 分块显示。
> 可以在设置里选择是否开启，开启后在开机自启动后就能运行和完成编辑与提醒

> 1.悬浮窗要设于桌面，任何窗口都能覆盖。
> 2.最下面部分编辑和分类排版有误且功能过于简单，两功能放于上方，
>   编辑点击后可以弹出一个新窗口（类似于离线待办清单软件中的编辑），
>   分类默认按日期分，今天 明天 七天内 之后（要附带具体日期）。
>   若一个界面足够则将这几个日期紧密排列，有待办事件后插入相应日期中，
>   直至一个页面放不下，这时可以鼠标滚轮下拉。
>   分类也可按照重要度或待办类型分类，在分类旁边设定一个三角点击即可更换分类类别。
> 3.整个界面排版有点拥挤，字号默认小一点，不要占满。
>   最后右上角要有设置按钮，可以调节字号 背景颜色 透明度 字体和字体颜色 是否关闭悬浮窗，
>   鼠标位于悬浮窗边缘即可移动与调整悬浮窗大小，调整大小后里面内容排版相应改变

> 悬浮窗背景透明度可以更改，默认为黑色 30%透明度，字体为宋体

> 任务加一项：保持字体的高清晰度为排版的最基本前提

> 字体清晰指的是字体分辨率保持高，在任何情况不能因为模糊像素低而看不清

> 上传时不要公布我的信息

## 七、工作纪律（照做，别问为什么）

1. **绝不能碰用户的真实数据。**
   - 真实库：`data/todo.db`（里面有用户的真实待办，**不要动**）
   - 测试必须隔离：`TODO_DATA_DIR=<项目路径>\data\test\xxx` + `TODO_PORT=8123`（或别的空闲端口）
   - 写数据的临时脚本必须用 `scripts/_isolation.py`（AGENTS.md 3.1 铁律一）
2. **不要碰用户正在运行的东西**（进程、端口、数据库连接）。
3. **★ 不要在测试里碰"项目的文件夹以外"。**
   这一条是 BUG-047 用一次真实误操作换来的：
   数据库能靠 `TODO_DATA_DIR` 隔离，**"启动文件夹"不能** ——
   结果跑一次测试就往用户真实的启动目录里写了一个 `.vbs`。
   **凡是会写注册表 / 启动文件夹 / 系统通知 / 计划任务的代码，测试里都要换成临时目录。**
4. **发现 Bug 先记录再修**，按七段式写进 `docs/问题记录与解决方案.md`
   （**同步更新索引表**，编号接 **BUG-048** 之后）。
5. **临时脚本用完立刻删**（`scripts/_` 开头，AGENTS.md 3.4）。
6. **改 Markdown 不要用 PowerShell 的字符串替换**（AGENTS.md 3.5 / BUG-031）。
7. **`except ...: pass` 不许写**（AGENTS.md 3.2 / BUG-044）——
   `check_errors.py` 第 11 节会自动拦。
8. **测试不许"只在某个时段通过"**（BUG-032 / BUG-045）。
9. **时间是"用户电脑的本地时间"**：只用 `datetime.now()`，
   **不许引入 UTC / 时区转换**（有测试拦着）。
10. **日期解析只有一个出口**：`app/core/timeutil.py` 的 `parse_flexible()`。
    **别在别处再写一套**（v0.4.3 之前就是两套，结果行为不一致，用户吃了亏）。
11. **发布前跑一次隐私复查**（`docs/上线前检查清单.md` 第七节）：
    路径 / 账号 / 数据三类都不能进仓库。
    **提交者身份用户明确要求不动。**
12. 改完文档跑 `python scripts/md2docx.py --all`（`.docx` 是交付物，虽然不进 Git）。
13. 改版本号要**同时改两处**并核对：
    `Select-String -Path app\config.py, installer\install.py -Pattern 'APP_VERSION ='`

## 九、故障速查

| 现象 | 先看哪儿 |
| --- | --- |
| 悬浮窗没出现 | ① 设置页「桌面悬浮窗」那一行的**状态说明**；② 点「立即显示」；③ 看 `data/floating/window.log` |
| 窗口日志里有 `HTTP 403` | 令牌不对 → 点设置页「重启窗口」 |
| 设置页显示"已停止自动重试" | 守护线程连续失败 10 次后主动停了 → 点「重启窗口」 |
| 窗口被别的程序盖住了 | **这是设计如此**（`always_on_top=False`）。右键标题栏勾「总在最前面」 |
| 字看着不够清楚 | 先把不透明度调到 100% 试试。**注意**：字本身是锐利的（DPI 感知已开），降低不透明度损失的是**对比度** |
| 日期怎么写都存不进去 | 看弹窗里的中文提示（会给出可照抄的例子）；解析逻辑在 `timeutil.parse_flexible()` |
| 提醒到点了没弹出来 | ① 先看日志里有没有「已发提醒：…」（v0.4.4 加的那条）——有就是发出去了，没有就是没到点/没扫描；② 设置页有个「发一条测试通知」按钮，点一下确认系统通知这条路通不通；③ 两条身份（自有 / 借用系统）在 Windows 11 上都实测能显示，自动模式选哪个都行 |
| 改了窗口大小不生效 | 应已修复（BUG-026 / BUG-036 / BUG-037）。若复现，记录到 BUG 列表 |
